# PM: browser-gui

- Users: students and occasional modellers who cannot or will not install Python; instructors who want a URL to hand out.
- Problem: the GUI needs a local Python process; signed desktop bundles were abandoned (#60).
- Scope decision (user, 2026-11-11): zero-install static web app, approach A. Phase 1 = seven steps, sample + uploaded met, terrain via AERMAP output or CSV upload, deck import. Phase 2 = AERMAP-wasm (GeoTIFF), then AERMET.
- Success criteria: see .10x/specs/2026-11-11-browser-gui-design.md ("Users and success criteria").
- Out of scope: regulatory use (banner on every step), KMZ export, run history.
